How It Works

Two simple link formats, automatic verse resolution

HTTPS

Web-Friendly Links

Use standard HTTPS URLs that work in browsers and automatically open Metanoia with App Link verification.

https://metanoia.bytecats.codes/bible/John/3/16
Custom Scheme

Direct App Links

Use the metanoia:// scheme for immediate deep links without web verification needed.

metanoia://bible/John/3/16
Flexible

Smart Resolution

Supports full book names, common abbreviations, and automatic chapter/verse validation.

https://metanoia.bytecats.codes/bible/jn/3/16

Integration Guide

Kotlin/Android

Launch Metanoia from your Android app with a specific verse reference:

val intent = Intent(Intent.ACTION_VIEW, Uri.parse("https://metanoia.bytecats.codes/bible/John/3/16")) startActivity(intent)

Web/HTML

Create clickable links that open Metanoia directly:

<a href="https://metanoia.bytecats.codes/bible/Romans/8/28">Read Romans 8:28</a>

JavaScript/Web

Programmatic links from web apps:

window.open('https://metanoia.bytecats.codes/bible/Genesis/1/1', '_self');

Frequently Asked Questions

What if Metanoia isn't installed?

The HTTPS link will open in a web browser. Users can then choose to install Metanoia from the link.

Does this work on iOS?

Currently Android-only. iOS deep linking support is planned for future releases.

Can I link to specific translations?

Not yet. Links open the user's currently selected translation. Translation-specific links are planned.

What about deuterocanonical books?

Currently only 66-book Protestant canon. Use full book names (e.g., "Tobit") for other canons until abbreviations are added.
